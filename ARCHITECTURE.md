# Архитектура

`santa.bot` обрабатывает Telegram-команды и callback-кнопки, редактирует текущую карточку и хранит ID карточки в FSM во время ввода текста. `santa.service` выполняет проверки прав и транзакционные операции. `santa.draw` строит допустимое взаимно однозначное распределение через ограниченное число попыток общего цикла и полиномиальный поиск полного соответствия. `santa.worker` доставляет сохранённые сообщения. `santa.models` описывает пользователей, игры, участников, исключения пар, назначения и очередь доставок.

Каждая игра имеет собственный токен приглашения и состояние `draft`, `registration`, `drawn` или `finished`. Назначения хранятся отдельно от профилей. Запрос полной таблицы проверяет и Telegram ID ведущего, и режим. Владелец бота не получает доступ к таблицам через интерфейс игры.

Жеребьёвка блокирует строку игры в PostgreSQL, проверяет состояние, рассчитывает распределение и сохраняет назначения вместе с сообщениями одной транзакцией. Уникальные ограничения на дарителя и получателя защищают от дублирования. Повторное подтверждение отклоняется.

Очередь доставки переживает перезапуск. Задания захватываются под блокировкой строки; индекс по состоянию и сроку ускоряет поиск следующего сообщения. Восстановление касается только захватов старше пяти минут. При ответе Telegram `RetryAfter` отправщик приостанавливает всю очередь на указанное время. Отправка в Telegram и запись в БД не являются общей транзакцией: при сбое между ними возможна повторная доставка. Строгую гарантию однократного отображения Telegram Bot API не предоставляет.

Схема обновляется Alembic на старте. Первая ревизия принимает существующие базы, добавляет недостающие поля и сохраняет данные; следующие изменения схемы оформляются отдельными ревизиями. Несколько экземпляров polling пока не координируются, поэтому бота запускают в одном процессе.

Панель владельца использует только агрегированные данные. Состояние отправщика хранится в памяти процесса и в сигнальном файле контейнера; проверка здоровья дополнительно опрашивает PostgreSQL. Ручной повтор рассылки доступен только для временных ошибок, исключая блокировки Telegram.
