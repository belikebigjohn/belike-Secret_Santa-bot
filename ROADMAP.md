# План развития

1. Довести основной сценарий до полного ТЗ: расширенный мастер, поля анкеты, редактирование дат, закрытие и архивирование игры, миграции Alembic.
2. Организаторские инструменты: UI ограничений пар, команды, помощники, безопасная замена участника с явным уведомлением.
3. Коммуникация: анонимные вопросы с модерацией, выборочные и запланированные объявления, управление уведомлениями.
4. Праздничный интерфейс: иллюстрации, обратный отсчёт, простые активности.
5. Системное управление: аналитика, сегментация и рекламные рассылки с подтверждённым согласием.
6. Эксплуатация: нагрузочные тесты, мониторинг, резервное копирование и стратегия миграции/восстановления.
