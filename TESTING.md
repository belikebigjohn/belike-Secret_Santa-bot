# Проверка

Установить зависимости разработки: `python -m pip install -e ".[dev]"`.

Запустить `python -m pytest -q` и `python -m ruff check .`.

Тесты покрывают три режима, отсутствие самоназначения и дублей получателей, запреты пар, несовместимые условия, повторную жеребьёвку, изоляцию игр, права на объявления, уникальность напоминаний после перезапуска, неизменяемость режима и список владельцев. Отправку в настоящий Telegram необходимо проверить отдельно с тестовым ботом и приватными чатами.
